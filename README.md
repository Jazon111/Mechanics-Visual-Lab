# 结构力学可视化实验室
**Visualization Laboratory of Structural Mechanics**

> 🌐 浏览器端结构力学虚拟仿真教学工具，纯前端，开箱即用。

## 📋 简介
面向土木工程教学的网页力学求解平台。将抽象内力计算可视化，快速生成剪力图、弯矩图，服务课堂演示、作业验算与虚拟实验。无需安装软件，打开网页即可运行。

## ✨ Features
- 简支梁：均布荷载、集中力、力偶多种加载模式
- 自动计算支座反力、剪力、弯矩，标记内力极值
- 参数实时修改，即时重算绘图
- 全部计算在浏览器本地完成，无后端依赖
- 支持静态托管部署，链接直接分享
